# CodeAlpha Task 3 – Data Visualization

## Overview
This project is completed as part of the **CodeAlpha Data Analytics Internship**.

The objective is to transform data into clear visualizations that reveal patterns and communicate insights effectively.

## Dataset
**Titanic Passenger Dataset**

The dataset contains passenger information such as survival status, passenger class, gender, age, and fare.

## Visualizations
1. Passenger Survival Distribution
2. Survival Rate by Gender
3. Survival Rate by Passenger Class
4. Passenger Age Distribution
5. Fare Distribution by Passenger Class
6. Correlation Matrix

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

Run:

```bash
python task3_visualization.py
```

The charts will be saved inside the `visualizations/` folder.

## Key Insights
- Survival rates differ considerably by gender.
- Passenger class shows a noticeable relationship with survival.
- Passenger ages are distributed across a broad range.
- Fare values vary considerably across passenger classes.
- The correlation matrix helps identify relationships among numerical variables.
